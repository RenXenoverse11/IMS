## System Overview

IMS is a web-based OJT (On-the-Job Training) management platform designed for use in telecom-grade internship environments. It supports two roles:

- **Intern** — logs attendance, tracks OJT progress, submits requests, and manages documents
- **Supervisor** — oversees assigned interns, approves requests, assigns tasks, and monitors attendance
